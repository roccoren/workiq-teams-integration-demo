About this demo

This demo shows how an application can query Microsoft Work IQ — the intelligence layer over Microsoft 365 — and use the results: grounded answers with citations, deep links into Teams/Outlook/SharePoint, document content retrieval, and a Teams bot surface.

Two engines:

  • Live — the WorkIQ MCP server (workiq mcp) over your real tenant.
  • Demo (mock) — the same surface over a sample Contoso knowledge base, no tenant needed.
